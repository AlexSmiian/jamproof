# Jamproof — навігатор без GPS

Android-навігатор для України, який продовжує вести, коли GPS глушать або підмінюють.

> 🚧 Застосунок у розробці. Перші збірки для бета-тестування з'являться в розділі [Releases](../../releases).

## Що вміє (план MVP)
- Бачить, коли GPS заглушено або він «бреше» (підміна), і перемикається на розрахунок
- Веде без GPS: сенсори телефона + вишки й Wi-Fi + прив'язка до доріг
- З OBD-адаптером ELM327 бере реальну швидкість з машини — точність без GPS значно вища
- Офлайн-карти, маршрути й голос українською
- Чесно показує, наскільки можна довіряти позиції: коло похибки і час без GPS
- Без ключів Mapbox, без «параметрів розробника» і без підміни GPS для інших застосунків

## Завантажити
Остання версія APK: **[jamproof.apk](../../releases/latest/download/jamproof.apk)** (з'явиться після першого релізу).

Застосунок оновлюється сам: перевіряє нові версії, підпис і контрольну суму файлу.

### Як встановити APK
1. Завантаж `jamproof.apk` з посилання вище
2. Відкрий файл → дозволь «Встановлення з невідомих джерел» для браузера
3. Samsung: якщо встановлення заблоковане — вимкни «Auto Blocker» у налаштуваннях безпеки
4. Xiaomi / Redmi / POCO: підтверди встановлення в діалозі MIUI/HyperOS

Вимоги: Android 10 або новіший.

## Приватність
- Позиція рахується на телефоні, на сервер не передається
- Логи поїздок надсилаються лише тоді, коли ти сам натиснеш «Надіслати розробникам»
- Дані про машину (профіль моделі) анонімні й не пов'язані з акаунтом
